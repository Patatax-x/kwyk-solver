# 🎓 Kwyk Tutor — Assistant IA pour kwyk.fr

> Extension Chrome et Firefox gratuite pour kwyk.fr. Comprends tes exercices de maths grâce à l'IA — pas juste les réponses.

## ✨ Fonctionnalités

- 📖 **Mode Pédagogique** — explication complète avec la règle et les étapes de calcul
- 💡 **Mode Indice** — coup de pouce sans dévoiler la réponse
- 😈 **Mode Troll** — démontre que l'IA maîtrise les exercices *(non conseillé pour apprendre)*
- 📝 **Mode Révision** — fiche interactive générée sur tout un devoir
- ⌨️ Raccourci **Ctrl+Entrée** pour afficher/masquer le panneau

## 🔧 Comment ça marche

1. Ouvre un exercice sur [kwyk.fr](https://www.kwyk.fr)
2. Clique le bouton violet **KT** en bas à droite
3. Choisis ton niveau d'aide : Explique, Indice ou Révision
4. L'IA analyse l'énoncé et génère une aide adaptée
