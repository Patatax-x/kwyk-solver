# Kwyk Tutor 🎓

> Assistant pédagogique IA pour [kwyk.fr](https://www.kwyk.fr) — comprends tes exercices de maths, pas juste les réponses.

[![Edge](https://img.shields.io/badge/Microsoft%20Edge-Installer-0078d4?logo=microsoftedge)](https://microsoftedge.microsoft.com/addons/detail/kwyk-tutor/cpfjdpkkflmobgfeadjhjlecfehlkblg)
[![Firefox](https://img.shields.io/badge/Firefox-Installer-FF7139?logo=firefox)](LIEN_AMO_ICI)

---

## ✨ Fonctionnalités

- 📖 **Mode Pédagogique** — explications étape par étape avec la règle et les calculs
- 💡 **Mode Indice** — coup de pouce sans donner la réponse
- 😈 **Mode Troll** — démontre que l'IA maîtrise les exercices *(non conseillé pour apprendre)*
- 📝 **Mode Révision** — fiche interactive générée sur tout un devoir
- ⌨️ Raccourci **Ctrl+Entrée** pour afficher/masquer
