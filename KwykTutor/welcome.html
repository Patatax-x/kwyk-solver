Bienvenue sur Kwyk Tutor !

Ton assistant pédagogique pour la plateforme de mathématiques kwyk.fr

📍 Comment ça marche ?

1

Va sur kwyk.fr et ouvre un devoir

L'extension se déclenche automatiquement sur tous les exercices de mathématiques.

2

Clique sur le bouton violet en bas à droite 🟣

Un bouton "KT" apparaît dans le coin inférieur droit de la page. Clique dessus pour ouvrir le panneau d'aide.

3

Choisis ton mode d'aide

Utilise Explique pour comprendre, Indice pour un coup de pouce, ou Réponse pour voir la solution.

⌨️

Raccourci clavier Appuie sur Ctrl + Entrée pour afficher/masquer rapidement le bouton et le panneau. Tu peux changer ce raccourci dans les options.

🚀 3 modes disponibles

📖

Pédagogique

Explications étape par étape pour vraiment comprendre

😈

Troll

Remplit automatiquement les réponses

📝

Révision

Fiche de révision interactive à la fin du devoir

⚙️ Avant de commencer

Une clé API IA est nécessaire pour faire fonctionner l'assistant. Mistral AI est recommandé — c'est gratuit sur console.mistral.ai. Génère une clé et colle-la dans les options.
